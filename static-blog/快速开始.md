# 静态博客快速入门指南

## 欢迎！

这是一个简洁优雅的静态博客网站，使用纯 HTML、CSS 和 JavaScript 构建。

## 🚀 快速体验

### 方法一：直接打开

1. 双击 `index.html` 文件
2. 网站会在浏览器中打开

### 方法二：使用本地服务器（推荐）

**使用 Python：**
```bash
cd static-blog
python -m http.server 8000
```
然后在浏览器访问：http://localhost:8000

**使用 Node.js：**
```bash
npm install -g http-server
cd static-blog
http-server
```

## ✏️ 如何添加新文章

### 第一步：创建文章内容

在 `articles/` 文件夹中创建新的 HTML 文件，例如 `my-article.html`：

```html
<p>这是文章的第一段...</p>

<h2>标题</h2>
<p>更多内容...</p>

<ul>
    <li>列表项 1</li>
    <li>列表项 2</li>
</ul>
```

### 第二步：添加文章信息

编辑 `data/articles.json`，添加新文章的信息：

```json
{
  "id": "my-article",
  "title": "我的新文章",
  "date": "2024-01-21",
  "author": "博主",
  "summary": "文章摘要...",
  "tags": ["标签1", "标签2"],
  "contentFile": "articles/my-article.html"
}
```

保存后刷新网站，新文章就会显示了！

## 🎨 个性化设置

### 修改网站标题

编辑 `index.html`，找到：
```html
<h1 class="page-title">思考·记录·分享</h1>
<p class="page-subtitle">在文字中寻找生活的诗意</p>
```
改成你想要的文字。

### 修改配色

编辑 `css/style.css`，在文件开头找到颜色变量：
```css
:root {
    --color-primary: #2c2c2c;    /* 主色调 */
    --color-accent: #8b7355;     /* 强调色 */
    --color-bg: #fafafa;         /* 背景色 */
}
```

### 修改个人信息

编辑 `about.html`，修改关于页面的内容。

## 🌐 部署到网上

### GitHub Pages（免费）

1. 在 GitHub 创建仓库
2. 上传所有文件
3. 在仓库设置中启用 GitHub Pages
4. 访问你的网站：`https://用户名.github.io/仓库名`
